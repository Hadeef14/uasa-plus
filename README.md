# UASA+

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

> ⚠️ **This is only a revision tool.** It does not replace school lessons, teachers, or official UASA papers.

A free revision tool for UASA. Learn, practise and level up.

Built by Hadeef Thaqif from SK Bukit Damansara.

---

## What it is

- **5 subjects** — Bahasa Melayu, English, Mathematics, Science, Sejarah
- **Lessons + quizzes** with real UASA-style questions
- **Mock exam mode** with timer and grading
- **Smart Review** — tracks what you get wrong
- **Streaks, XP, hearts, levels** — gamified practice
- **Reward shop** — spend XP on power-ups and themes
- **Teacher Studio** — create lessons, manage a class
- **Works offline** — installable PWA
